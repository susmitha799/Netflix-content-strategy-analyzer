Objective

This task focuses on loading and preprocessing the Netflix Movies and TV Shows dataset. The objective is to clean and transform the dataset to prepare it for exploratory data analysis and further insights generation.

Steps Performed

Loaded the Netflix dataset using Pandas.

Checked for missing values and handled them using appropriate imputation techniques.

Removed duplicate records to ensure data integrity.

Normalized categorical features such as type, country, rating, and genres for consistency.

Saved the cleaned dataset for further analysis and visualization.
